🔐 認證與授權

🔴
硬編碼測試帳號密碼
AccountController.cs 中存在硬編碼的測試帳號密碼，生產環境需移除
{ "admin", ("admin123", new[] { "Admin" }) }
🟡
JWT Token 過期時間過長
Token 過期時間設為 8 小時 (480 分鐘)，建議縮短並實作 Refresh Token
_jwt.GenerateToken(logon.UserName, 480)
🟢
JWT 簽名驗證
使用 HMAC-SHA256 演算法進行簽名，密鑰從設定檔讀取
🟢
Issuer 驗證啟用
ValidateIssuer = true，可防止 Token 被其他系統使用

💉 注入攻擊防護

🟢
SQL Injection 防護
使用 Entity Framework Core 參數化查詢，有效防止 SQL 注入
🟢
LINQ 查詢安全
所有查詢使用 LINQ 方法語法，避免字串拼接
🟡
XSS 防護
前端需確保使用 Vue.js 的自動轉義功能，避免使用 v-html

📁 檔案上傳安全

🟢
檔案雜湊檢測
使用 SHA-256 計算檔案 Hash，可偵測重複檔案
SHA256.Create().ComputeHashAsync(stream)
🟡
檔案類型驗證
建議加入 MIME Type 白名單驗證，目前僅依賴副檔名
🟢
安全檔名處理
使用 GUID 重新命名檔案，避免路徑遍歷攻擊
$"{Guid.NewGuid()}{extension}"

⚙️ 設定安全

🔴
開發環境敏感資料記錄
EnableSensitiveDataLogging 在開發環境啟用，需確保生產環境關閉
options.EnableSensitiveDataLogging();
🟢
CORS 設定
從設定檔讀取允許的來源，未使用 AllowAnyOrigin
🟢
設定驗證
JWT 設定必填項目有驗證機制，缺少時會拋出例外

📋 輸出提示詞

PetSalon 專案架構分析報告： 這是一個 .NET 8 Web API + Vue.js 3 多層架構系統，用於寵物美容沙龍管理。 【架構層級】 - 前端層：Vue.js 3 + PrimeVue + Pinia，包含 Dashboard、寵物管理、預約日曆等模組 - API 層：14 個 Controllers 處理 RESTful API 請求 - 服務層：11 個 Service 類別實作商業邏輯 - 資料層：Entity Framework Core 8.0 + SQL Server，15 個資料實體 【安全建議】 - 需移除 AccountController 中的硬編碼測試帳號 - 建議縮短 JWT Token 過期時間並實作 Refresh Token - 確保生產環境關閉 EnableSensitiveDataLogging
